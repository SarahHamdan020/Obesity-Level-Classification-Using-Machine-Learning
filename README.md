# Obesity Level Classification Using Machine Learning

**Course:** Introduction to Artificial Intelligence (COE 292)  
**Team Project:** 4 members  
**Tools/Tech:** Python, scikit-learn, DNNs, KNN, SVM, data preprocessing, cross-validation

## Project Overview
Developed a multi-class classification system to estimate obesity levels from dietary, lifestyle, and physical activity data. The project used a real-world dataset of 2,111 instances with 16 features.

## Features
- Implemented and compared KNN, SVM, and Deep Neural Network (DNN) models
- Applied data preprocessing and feature scaling (StandardScaler)
- Used 10-fold cross-validation for robust evaluation
- Achieved ~97% accuracy with strong performance across multiple obesity categories
